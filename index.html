PROJECT / 01

SnapMind – AI Screenshot Organizer

A full-stack app for organising screenshots. It runs OCR on each image and uses Gemini to sort it into one of 13 categories, with Groq as a fallback if Gemini is unavailable. It also picks out details such as amounts, dates, emails, phone numbers and order IDs from the extracted text. Users sign in with JWT authentication and email verification.

React Node.js Express MongoDB Tesseract.js Gemini API

PROJECT / 03

Airbnb Pricing and Urban Air Quality Dashboard

A data visualization project that looks at how Airbnb nightly prices relate to city-level air quality (AQI), covering 45 metropolitan areas and 16,050 listings. The data comes from a synthetic data-generation workflow, so it is not live or real-world collected data. I used correlation tests, ANOVA and OLS regression, and built a Streamlit dashboard with maps and filters. The results show statistical associations only, not causation.

Python Pandas NumPy SciPy Statsmodels Plotly Streamlit
