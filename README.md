A streaming platform with a React frontend and a Node.js/Express backend. It has search by title and genre, a watchlist and a custom video player, with Firebase for authentication and storage.

**Audio Deepfake Detection**

## Run locally

Keep `index.html` and the resume PDF in one folder and open `index.html` in a browser. The page loads the Manrope font from Google Fonts, so it needs an internet connection to show that font. Without one it falls back to a system font.

## Deploy

**AWS S3:** upload `index.html` and `Sameer Kumar Resume.pdf` to the root of the bucket and make both files publicly readable.

**GitHub Pages:** in the repo, open Settings → Pages, choose the Static HTML workflow (or deploy from the `main` branch, root folder), and wait for the build to finish.

The resume filename has to stay exactly `Sameer Kumar Resume.pdf`, since the page links to `Sameer%20Kumar%20Resume.pdf`.
